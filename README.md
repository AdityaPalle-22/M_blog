
# m_blog

m_blog is a modern, lightweight blogging platform built for developers and content creators who want a clean and efficient way to publish articles online. The application supports blog creation, content management, and rich text formatting in a user-friendly interface.

## Overview

m_blog enables users to:

- Create, edit, and delete blog posts
- Format content using Markdown-based rich text tools
- Manage content in a responsive, intuitive interface
- Deploy and customize the platform with minimal setup effort

## Features

- Post creation and management
- Rich text and Markdown-based formatting
- Responsive design for desktop and mobile devices
- Simple configuration and deployment workflow
- Clean, developer-friendly project structure

## Getting Started

### Prerequisites

Before running the project, ensure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Bkarthik07/m_blog.git
   ```

2. Navigate to the project directory:
   ```bash
   cd m_blog
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

The application should now run locally in your development environment.
